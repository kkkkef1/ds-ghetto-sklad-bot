# sliv-bot

Discord-бот для GTA5 RP-сервера: находит сливы склада фракции (несовпадение
между тем, что фракция взяла со склада, и тем, что реально было размещено/
осталось), считает нарушителей и формирует отчёт с готовыми командами
наказания. Отдельно от этого в тот же бот встроен учёт каптов между
фракциями (`capt-tracker`) с автоматическими сводками и лимитами.

pnpm-монорепо: логика анализа логов вынесена в отдельный пакет
(`lib/log-analyzer`), сам Discord-бот — тонкая обвязка над ним
(`apps/discord-bot`).

## Структура репозитория

```
apps/discord-bot/     Discord-бот (discord.js): визард сессии, слэш-команды,
                       учёт каптов (captTracker/)
lib/log-analyzer/      Чистый TS-пакет без зависимости от Discord: парсинг
                       логов, сопоставление take/give, начисление наказаний,
                       генерация отчёта — используется ботом, но не завязан
                       на него, можно тестировать/переиспользовать отдельно
deploy/                Конвенция для systemd-юнитов и заметки по будущему
                       боту-оркестратору нескольких ботов
```

Подробная документация — в README каждого пакета:

- **[apps/discord-bot/README.md](apps/discord-bot/README.md)** — установка,
  переменные окружения, регистрация слэш-команд, полное описание команд
  бота (`/sliv`, `/stopsliv`, `/capt`, `/announce`) и того, как устроен

- **[deploy/README.md](deploy/README.md)** — конвенция для деплоя как

## Что делает бот

### `/sliv` — анализ слива склада

1. Проверяет, что у пользователя нет активной сессии, создаёт приватный
   канал (виден только автору и боту).
2. Пошаговый визард: фракция → лог склада → логи размещений (дом/квартира/
   машины/семья, можно несколько сообщений и файлов) → состав фракции
   (опционально) → фамилия админа.
3. Сопоставляет «взял со склада» и «положил» по каждому серийному номеру
   (оружие) и по времени в пределах окна (патроны/аптечки — без серийников),
   с учётом того, что предмет мог быть забран обратно.
4. Отдаёт `.txt`-отчёт с нарушителями, начисленным наказанием и текстом-
   доказательством для каждого.

Большие логи (сотни тысяч строк) не блокируют бота целиком — обработка
кооперативно уступает event loop небольшими порциями, так что бот остаётся
отзывчивым, пока считает.

### Учёт каптов (`capt-tracker`)

Читает канал с забивами каптов, ведёт дневные счётчики атак/защит по
фракциям, публикует сводку с кнопкой отмены в оба сервера-назначения и
подсвечивает превышение дневного лимита (правило 1.2). Управляется через
`/capt` (список помощников, сводка, ручная правка счётчика, сброс дня).

### `/announce`

Публикация сообщения от имени бота в любой канал на любом сервере, куда
бот приглашён — например, для оповещений, не привязанных к конкретной
сессии. Доступно только создателю бота.

## Быстрый старт

```bash
pnpm install
cp apps/discord-bot/.env.example apps/discord-bot/.env
# заполните .env — см. apps/discord-bot/README.md
pnpm --filter @workspace/discord-bot run deploy-commands
pnpm --filter @workspace/discord-bot run dev
```

Полный список требований (Discord-приложение, права, intents, ID категории
для сессий) — в [apps/discord-bot/README.md](apps/discord-bot/README.md).

## Разработка

```bash
pnpm --filter @workspace/log-analyzer run typecheck
pnpm --filter @workspace/discord-bot run typecheck
pnpm --filter @workspace/discord-bot run build   # esbuild → apps/discord-bot/dist/index.js
```

`lib/log-analyzer` не зависит от `discord.js` и не читает переменные
окружения — весь ввод приходит через `AnalysisInput` (см.
`lib/log-analyzer/src/types.ts`), что позволяет гонять анализ на
произвольных логах в тестах/скриптах без поднятия самого бота.

## Известные ограничения

- Активные сессии `/sliv` хранятся в памяти процесса — рестарт бота
  посреди визарда теряет состояние сессии (созданный канал при этом
  остаётся).
- Список крайм-фракций (`lib/log-analyzer/src/factions.ts`) содержит
  реальные id серверных фракций — при переносе на другой сервер их нужно
  заменить.

Подробнее — раздел «Открытые вопросы / TODO перед продакшеном» в
[apps/discord-bot/README.md](apps/discord-bot/README.md).
