# logcheck — сводка по логам за сутки (`/lcheck`)

Раз в сутки (по умолчанию в **00:10 МСК**) бот читает логи действующих фракций (общий список со складом и твинками,
`/sklad faction add|remove`) за **вчера, 00:00–23:59 МСК**, и присылает в отдельный канал сводку.
Выгрузка устроена так же, как у склада: все логи фракции за сутки, затем разбор в боте. Тот же аккаунт и та же очередь
на сайт (если в 00:10 идёт склад или твинки, проверка дожидается своей очереди).

## Вид сводки

```
**Сводка за 20.11.2026 с 00:00 по 23:59**

**Участие в ПВП-мероприятиях (война за ресурсы):**
> Bloods ........... 14
> Families ......... 9
> Marabunta ........ 0 ⚠️

**Действия требующие внимания:**
> Bloods: 2
```
62 Darius_Carter [216407] Bloods Устанавливает Lord_Nunchake отдел дебил. 20.11.2026, 14:26:09  ⟵ ДЕБИЛ
1452 Yamato_Outlaw [532573] Bloods Увольняет Svyat_Depressed[633939] с причиной "ты лох". 20.11.2026, 21:34:09  ⟵ ЛОХ
```
> Families: чисто ✅
> Marabunta: чисто ✅
```

- На день ВЗХ вместо «ПВП за сутки не было» показывается блок с числом вывезенных хаммеров по фракциям (фракция без вывоза: `0 ⚠️`):

```
**ВЗХ — вывезено хаммеров:**
> Bloods ........... 5
> Families ......... 0 ⚠️
> Marabunta ........ 0 ⚠️
```
  Если в один день есть и входы, и хаммеры, показываются оба блока.
- Захват черного рынка идёт отдельным блоком (если хоть одна фракция участвовала):

```
**Захват черного рынка — участвовало:**
> Bloods ........... 12
> Families ......... 7
> Marabunta ........ 0 ⚠️
```
  Фраза «ПВП за сутки не было» относится к войнам и ВЗХ: если их не было, она остаётся, а блок черного рынка идёт ниже.
- Блок кода под фракцией показывается только если есть что показать.
- Фракция, которую не удалось прочитать, помечается `⚠️ не удалось проверить` (а не «чисто»); подробности ошибки — владельцу в личку.
- Если страницы логов кончились раньше начала суток (слишком много строк), помечается `⚠️ данные неполные`.
- Сообщение длиннее лимита Discord делится на несколько, блок кода не рвётся.

## Что проверяется

| Строка лога | Что берём |
|---|---|
| `Повышает … с причиной "…"` / `Понижает …` / `Увольняет … с причиной "…"` | текст причины |
| `Устанавливает … отдел …` | текст после слова «отдел» |
| `Увольняется по собственному желанию` | не берём (причины нет) |
| `Входит на территорию войны за …` | ПВП-участие: уникальные игроки **по ID** персонажа, по фракциям; событие (выживание / ресурсы / спасение) определяется по тексту |
| `вывозит хаммер с территории и получает N материалов …` (автор `SYSTEM [1]`) | **ВЗХ**: входов в логах нет, поэтому считаем **число таких строк** = вывезенных хаммеров по фракции (материалы не важны). На ВЗХ-день вместо «ПВП за сутки не было» сводка показывает блок `**ВЗХ — вывезено хаммеров:**` |
| `участвует в захвате черного рынка.` (или «чёрного») | **Захват черного рынка** (раз в сутки): уникальные участники **по ID** персонажа по фракциям. Показывается отдельным блоком `**Захват черного рынка — участвовало:**` после войн и ВЗХ |

Причины сравниваются со списком слов (`/lcheck words list`): регистр, «ё»=«е», латинские и цифровые двойники (`x`→`х`, `0`→`о`),
растянутые буквы (`лоооох`) и буквы через точки/пробелы (`л.о.х`) учитываются. «Спорные» слова (КРЫСА, ПЕТУХ, СЛИВ…) помечаются `(спорное)`.

Пометки в словах: `ЛОХ` — слово с окончаниями до 2 букв; `=СУКА` — только эта форма; `ХУЙ*` — любое слово на это начало; `МАТЬ ТВОЮ` — фраза.

## Недельная сводка по ПВП

Каждый **понедельник в 00:30 МСК** бот присылает в тот же канал сводку за прошедшую неделю (понедельник–воскресенье). Формат простой:
блок на фракцию, в нём по строке на тип мероприятия: сколько стало за неделю и сколько было на прошлой.

```
**Недельная сводка за 16.11 – 22.11**

**Bloods**
> ПВП-войны: 29 участий (было 22) 📈
> ВЗХ: 10 хаммеров (было 3)
> Черный рынок: 81 участие (было 63) 📈

**Families**
> ПВП-войны: 15 участий (было 32) 📉
...

-# 📈 / 📉 — изменение больше чем на четверть к прошлой неделе. «Участие» — один игрок на одном мероприятии.
```

- Сводка собирается из **дневных итогов** (только счётчики, без самих логов), которые бот запоминает при каждой дневной проверке
  (в `data/logcheck-store.json`, последние 120 суток). Сайт при этом не читается.
- «Участие» = один игрок на одном мероприятии (войны и черный рынок); ВЗХ считается в хаммерах. Строка типа есть, если мероприятие было
  на этой или на прошлой неделе.
- **Если за какие-то сутки недели данных нет**, ошибки нет: складываются те сутки, что есть, а внизу короткая пометка `ℹ️ Учтено суток: 5 из 7`.
- **Стрелки 📈/📉 ставятся только при честном сравнении**: данных за обе недели поровну суток и мероприятий этого типа поровну.
  Иначе (например, 5 суток против 7) цифры показываются без стрелок, а внизу пометка. Изменение должно быть больше чем на 25%
  и не меньше чем на 2–3 единицы (чтобы 1 → 2 не считалось «ростом»).
- Нет данных за прошлую неделю: цифры без «было» и пометка. Нет данных вообще: короткое сообщение «Данных за эту неделю нет».
- Первые недели после запуска данных может не хватать. Недостающие сутки можно дозаполнить командой `/lcheck run date:ДД.ММ.ГГГГ` (без `post`):
  итоги суток запомнятся.
- Если дневная проверка за воскресенье в 00:30 ещё не закончилась (очередь на сайт), недельная сводка ждёт её до 06:00, потом уходит как есть.
- Отключить: `/lcheck weekly enabled:false`. Посмотреть любую прошедшую неделю: `/lcheck week` (результат виден только вам, `post:true` отправляет в канал).

## Логи не хранятся

Строки логов существуют только в памяти на время проверки. На диск пишутся лишь настройки (`data/logcheck-store.json`:
канал, время, список слов), пометки «сутки проверены» (последние 60) и счётчики ПВП по суткам для недельной сводки (последние 120). Сутки помечаются проверенными только после того,
как сводка дошла до канала; при сбое проверка повторяется через 20 минут (до 3 раз), потом сообщение владельцу.

## Команды `/lcheck` (создатель и модераторы, главный сервер)

| Команда | Что делает |
|---|---|
| `/lcheck status` | настройки, очередь на сайт, результат последней проверки |
| `/lcheck channel` | канал сводок (выбор или `id`/ссылка, в том числе на другом сервере с ботом) |
| `/lcheck time` | во сколько запускать (МСК), по умолчанию 00:10 |
| `/lcheck enable` / `disable` | включить / выключить проверку по расписанию |
| `/lcheck run [date] [faction] [post]` | ручная проверка суток (по умолчанию вчера). Без `post` результат видите только вы и сутки не засчитываются; `post:true` отправляет сводку в канал, повторно за уже отправленные сутки бот спросит подтверждение кнопками |
| `/lcheck weekly enabled:` | включить / выключить недельную сводку по ПВП |
| `/lcheck week [date] [post]` | недельная сводка за любую прошедшую неделю (по умолчанию прошлую): без `post` видите только вы, `post:true` отправляет в канал |
| `/lcheck words list / add / remove / reset` | список слов (сброс спросит подтверждение кнопками) |

Автопроверка не стартует, если: выключена, не задан канал (`/lcheck channel`), не задан `WH_OWNER_ID`.
Если бот был выключен в нужный момент, он наверстает вчерашние сутки, как только поднимется (в течение того же дня).
